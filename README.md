# Sam Fender Fan Site

An independent fan-made guide to Sam Fender: his music, North Shields roots, awards, live performances, tours, venues, and show-by-show setlists.

## Highlights

- Interactive concert archive organized by year, country, city, and venue
- Setlists and source links for performances from 2013 onward
- Integrated live-performance videos
- Albums, deluxe editions, live releases, singles, and features
- Responsive layouts for desktop and mobile

## Run locally

This is a static website with no build step. Open `index.html` directly or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
